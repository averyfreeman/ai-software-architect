# Architecture comparison bundle

This installed bundle is the bounded comparison contract for open architecture and pattern decisions.

Use the categorized names and canonical links in the sibling reference files. Compare two to five genuine alternatives for one material decision using the localized six-column table:

- Option
- Fit
- Rationale
- Main benefit
- Main liability
- Material assumption

Fit is an ordinal NN/100 score, not a probability. Repeat the selected Option cell exactly in Recommendation, keep supporting patterns separate, and end with visible user-decision guidance offering approval, revision, or more information.
